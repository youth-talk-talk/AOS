# REST API 테스트 자동화 PRD

## 목표
- 각 서비스별로 REST API 테스트 코드를 작성한다.
- MockWebServer를 활용하여 외부 의존성 없이 테스트를 수행한다.

## 요구사항
- MockWebServer 의존성은 이미 추가되어 있음
- 각 서비스별로 API 테스트를 작성해야 함
- 테스트 커버리지는 최대한 높게 유지한다

## 서비스 목록
- UserService
- AuthService
- ProductService
- OrderService
- PaymentService

## 기타
- 테스트는 JUnit5 기반으로 작성
- 테스트 데이터는 별도 유틸리티 클래스로 관리
